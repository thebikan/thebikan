## Engineering Philosophy

<table>
<tr>

<td width="33%" valign="top">

<sub>01</sub>

**Simple by default**

Complexity should be earned, never assumed. The best solution is usually the one with the fewest moving parts.

</td>

<td width="33%" valign="top">

<sub>02</sub>

**Built to last**

Readable, maintainable code outlives clever code. Ship things the next engineer can reason about.

</td>

<td width="33%" valign="top">

<sub>03</sub>

**Useful above all**

Software is only good if it genuinely helps someone. Value first, implementation details second.

</td>

</tr>
</table>
